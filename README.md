# Чужой телефон

Ежедневная детективная игра: каждый день открывается новая порция найденного вымышленного телефона (чаты, фото, заметки, история поиска). Все игроки вместе раскручивают одно дело 5-7 дней, в конце сезона голосуют, кто виноват.

## Что в прототипе
- `public/index.html`: интерфейс, PWA (manifest, service worker, иконки), без сборки
- `public/case.js`: дело №001 в виде данных. Каждая улика имеет `day`, по нему она открывается
- Переключатель «Демо: день» заменяет реальную дату. В продукте день считается от старта сезона
- Блокнот детектива: отмеченные улики, подозреваемые, голосование (с последнего дня), комментарии по дням

## Дальше

## Деплой на Cloudflare
Сайт целиком лежит в `public/`, сборки нет.

- **Workers (static assets):** `wrangler.jsonc` уже настроен, имя проекта `claudefire`. Локально: `npx wrangler dev`, выкатить: `npx wrangler deploy`. Для автодеплоя из GitHub: Workers & Pages, Create, Import a repository, `main`; команда сборки пустая, команда деплоя `npx wrangler deploy`.
- **Pages:** Create, Pages, Connect to Git. Framework preset: None, build command пустая, build output directory: `public`.
