# Чужой телефон

Ежедневная детективная игра в браузере. Каждый день открывается новая порция найденного вымышленного телефона: переписки, галерея, заметки, история поиска. Все игроки вместе раскручивают одно дело 5-7 дней, а в конце сезона голосуют, кто виноват.

Смесь Wordle, true crime и screenlife-хорроров. Причина возвращаться: новые улики каждый день, а теории и спойлеры обсуждаются в комментариях.

## Статус

Прототип интерфейса. Работает на локальных данных, без сервера. Дело №001 «Тишина после 23:40» написано вручную как образец формата.

- Репозиторий: https://github.com/fenix3f/strangers-phone
- Деплой: Cloudflare Workers (static assets), https://strangers-phone.muddy-cake-fb65.workers.dev/

## Что есть в прототипе

- Экран блокировки с замороженным временем последней активности и батареей 3%
- Домашний экран и четыре приложения: Сообщения, Фото, Заметки, Браузер (история поиска)
- Улики открываются по дням. Переключатель «Демо: день» заменяет реальную дату
- Любую улику можно отметить. Отмеченное попадает в «Блокнот детектива»
- Блокнот: улики, подозреваемые, голосование (открывается в последний день), комментарии по дням без спойлеров из будущего
- PWA: manifest, service worker, иконки, установка на домашний экран iPhone

## Структура

```
public/
  index.html            интерфейс (HTML, CSS и JS в одном файле, без сборки)
  case.js               дело в виде данных
  manifest.webmanifest  манифест PWA
  sw.js                 service worker: кэш оболочки, case.js всегда свежий
  _headers              заголовки Cloudflare
  *.png                 иконки
wrangler.jsonc          конфиг Cloudflare Workers, имя проекта claudefire
```

## Формат дела (`case.js`)

Всё, что открывается по дням, имеет поле `day` от 1 до `days`.

- `chats[]`: переписки, у каждой `msgs[]` с `day`, `from` (`me` или `them`), `t`, `text`, необязательно `deleted`
- `photos[]`: `day`, `title`, `time`, `place`, `tones`, `desc`
- `notes[]`: `day`, `title`, `time`, `text`
- `searches[]`: `day`, `time`, `q`
- `suspects[]`: `id`, `name`, `role`, `hint`
- `comments[]`: демо-комментарии для прототипа

Решение дела (кто виноват) в клиент не кладём. Оно должно приходить с сервера после голосования.

## Как делать дело

Скелет дела пишем руками: кто виновен, когда, мотив, какие улики что доказывают. LLM расписывает сообщения и заметки по готовому скелету. У дела один виновный, улики его доказывают, а в профиле детектива считаем, насколько рано игрок угадал.

## Запуск локально

```
cd public
python3 -m http.server 8000
```

Открыть http://localhost:8000. Через `file://` страница тоже открывается, но service worker не включится.

## Деплой на Cloudflare

Сайт целиком в `public/`, сборки нет.

- **Workers (static assets):** `wrangler.jsonc` уже настроен. Локально `npx wrangler dev`, выкатить `npx wrangler deploy`. Автодеплой из GitHub: Workers & Pages, Create, Import a repository, ветка `main`, команда сборки пустая, команда деплоя `npx wrangler deploy`.
- **Pages:** Connect to Git, framework preset None, build command пустая, build output directory `public`.

## Монетизация (позже)

- Сезонный пасс: ранний доступ к уликам, архив дел
- Косметика профиля детектива
- Брендированные дела: бренд платит за интеграцию в сюжет
- Маркетплейс пользовательских дел с долей

Юридических рисков нет: всё вымышленное.
