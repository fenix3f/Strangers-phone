# Чужой телефон

Ежедневная детективная игра: каждый день открывается новая порция найденного вымышленного телефона (чаты, фото, заметки, история поиска). Все игроки вместе раскручивают одно дело 5-7 дней, в конце сезона голосуют, кто виноват.

## Что в прототипе
- `index.html`: интерфейс (PWA-основа, без сборки, открывается двойным кликом)
- `case.js`: дело №001 в виде данных. Каждая улика имеет `day`, по нему она открывается
- Переключатель «Демо: день» заменяет реальную дату. В продукте день считается от старта сезона
- Блокнот детектива: отмеченные улики, подозреваемые, голосование (с последнего дня), комментарии по дням
